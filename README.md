

# 电商设计台

基于AI驱动的电商主图与详情页一键生成工具，帮助电商卖家快速生成专业的AI图片提示词。

## 功能特性

### 6步智能工作流
1. **固定输入收集** - 上传产品图，填写产品基本信息
2. **竞品研究** - 联网搜索竞品或手动输入，AI结构化分析
3. **变量推荐** - AI推荐视觉风格、主图张数、详情屏数、内容节奏
4. **差异化策略** - 生成差异化的主图和详情页策略
5. **平台尺寸适配** - 自动适配电商平台的最佳尺寸
6. **提示词生成与生图** - 生成可复制提示词，一键调用gpt-image-2生成图片

### 多API支持
- **文本LLM**：支持 Chat Completions API / Responses API / Claude Messages API
- **图片LLM**：支持 Images API (/v1/images) 或 Responses API (/v1/responses)
- **联网搜索**：集成 Tavily Search API

### 核心亮点
- 📋 **一键生成** - 从产品信息到完整提示词，全程AI辅助
- 🎨 **图生图** - 基于上传的产品图，直接生成电商主图/详情页
- 📋 **一键复制** - 每条提示词独立可复制
- 📥 **批量导出** - 导出全部提示词为Markdown文件
- 💾 **本地存储** - 所有配置和进度自动保存到浏览器

## 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/BLUE0818/ecom-design-desk.git
cd ecom-design-desk

# 2. 安装依赖
npm install

# 3. 启动服务
npm start

# 4. 打开浏览器
# 访问 http://localhost:3000
```

### 首次使用配置

1. 打开页面后，点击右上角 **API设置**
2. 配置 **文本LLM**（用于AI分析和生成）：
   - 选择API模式
   - 选择供应商预设或自定义
   - 填入 API Base URL 和 API Key
   - 填入模型名称
3. 配置 **图片LLM**（用于生图，可选）：
   - 填入 OpenAI 兼容的 API Base URL
   - 填入 API Key
4. 配置 **联网搜索**（可选，用于竞品研究）：
   - 启用 Tavily 搜索
   - 填入 Tavily API Key（免费获取：[tavily.com](https://tavily.com)）

## 使用指南

### 基本流程

```
上传产品图 → 填写信息 → 竞品研究 → 确认变量 → 生成策略 → 适配尺寸 → 生成提示词 → 生成图片
```

### Step 1: 固定输入
- 上传1张产品图片
- 填写产品名称、类目、核心参数、卖点等14项信息
- 生成输入确认卡

### Step 2: 竞品研究
- **联网模式**：自动搜索同平台、同品类竞品
- **手动模式**：自行粘贴竞品信息
- AI分析输出结构化竞品摘要

### Step 3: 变量推荐
- AI推荐视觉风格、主图张数、详情屏数、内容节奏
- 可直接确认或微调

### Step 4: 差异化策略
- 自动生成差异化主题
- 逐张主图策略
- 逐屏详情页结构

### Step 5: 平台尺寸
- 自动适配目标平台的最佳尺寸
- 主图和详情页的尺寸、比例、版式建议

### Step 6: 提示词生成与生图
- 生成可复制的AI提示词
- 一键生成图片（gpt-image-2 图生图模式）
- 支持下载、重新生成
- 导出全部提示词为Markdown

## 为什么需要代理服务器？

由于浏览器的CORS（跨域）限制，直接调用大多数AI API会被拦截。代理服务器负责：
1. 转发前端的API请求到真实的AI服务
2. 添加正确的认证头（支持Bearer token和x-api-key）
3. 处理FormData格式的图片上传
